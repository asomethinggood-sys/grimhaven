* روح نوزاد: ۴۸ ساعت مداوم (با هشدار خطر تهاجم بیرونی در چت).
* انشعاب روح و بالاتر: ۷۲ ساعت خلوت‌نشینی کامل معنوی.

[تصفیه چی] ──────► باز شدن اسلات سلاح، نبردهای تک‌به‌تک ساده علیه هیولاهای دشت
     │
[پی‌ریزی بنیاد] ──► دسترسی به بازار پاویون، امکان پیوستن به فرقه، فعال‌سازی کاتالیزورهای رده ۲
     │
[هسته طلایی] ────► پرواز با شمشیر (کاهش زمان جابجایی)، حس الهی فعال در رادار، مصونیت به صدمات فانی
     │
[روح نوزاد] ─────► فن دورنوردی (Teleport) در مبارزه، جان دوم (در صورت مرگ، روح نوزاد فرار می‌کند)
     │
[انشعاب روح] ────► فعال‌سازی هاله قلمرو شخصی (Domain)، ایمنی در برابر جادوهای توهمی و روانی
     │

     │
[صعود به مصیبت] ──► امکان مجهز کردن آرتیفکت‌های باستانی الهی، درخشش طلایی پروفایل در چت‌های سرور

* ضرایب عددی جهش قدرت:
   * ورود به پی‌ریزی بنیاد: سلامت کالبد (HP) \times 3 | ظرفیت چی \times 4 | مقاومت فیزیکی +50\%.

فصل ۳: موتور شانس کارمایی، فرمول بریک‌ترو و شکست‌ها
۳.۱. فرمول قطعی محاسبه موفقیت در بریک‌ترو (Breakthrough Formula)
در پایان زمان خلوت‌نشینی، این معادله دقیق ریاضی اجرا می‌شود:
\text{Success Rate (\%)} = \text{Base} + (\text{Dao Heart} \times 0.3) + \text{Pill Bonus} + (\text{Luck} \times 0.2) - (\text{Corruption} \times 0.5) - \text{Penalty}
* \text{Base} (پایه پیش‌فرض): 50\% برای لایه‌های عادی، 25\% برای جهش بین قلمروهای اصلی.
* \text{Dao Heart}: مقداری از ۰ تا ۱۰۰ (تأثیر مثبت بر تمرکز).
* \text{Pill Bonus}: درصد اختصاصی قرص‌های مصرفی (مثلاً قرص بنیاد: +20\%).
* \text{Luck}: آمار پنهان شانس کارمایی (۰ تا ۱۰۰).
* \text{Corruption}: درصد فساد شیطانی (برای ارتدوکس‌ها به شدت آسیب‌زا است).
* \text{Penalty} (جریمه سنگینی قلمرو):
   * تصفیه چی: 0\%
   * پی‌ریزی بنیاد: 10\%
   * هسته طلایی: 20\%
   * روح نوزاد: 35\%
   * انشعاب روح: 50\%
   * پژواک خلاء: 65\%
   * صعود به مصیبت: 80\%
۳.۲. پیامدهای سه‌گانه شکست در صعود (Breakthrough Failure States)
در صورتی که عدد تاس سرور بالاتر از شانس موفقیت بیاید، بر اساس جدول احتمالات زیر یکی از سه سناریو رخ می‌دهد:

        ┌────────────────────────────┼────────────────────────────┐

1. شکست خفیف (Minor Failure) — شانس رخداد ۶۰٪:
   * پیامد: ۳۰٪ از چی انباشته می‌سوزد. مریدین‌ها به مدت ۶ ساعت مسدود می‌شوند (نرخ بازدهی AFK در این مدت ۵۰٪ افت می‌کند).
2. انحراف چی و رخنه شیاطین (Qi Deviation) — شانس رخداد ۳۰٪:
   * پیامد: سقوط یک زیرمرحله (مثلاً از اواخر به میانه). کاراکتر دچار جنون موقت شده و ۱۰٪ از سنگ‌های روح داخل کوله‌پشتی به دلیل هذیان مصرف می‌شود.
3. نابودی توسط خشم فلک (Tribulation Annihilation) — شانس رخداد ۱۰٪:
   * شرط وقوع: ویژه قلمرو هسته طلایی به بالا در صورت عدم تجهیز آرتیفکت دفاعی.
   * پیامد: صاعقه مصیبت بدن را نابود می‌کند. بازیکن به لایه ۱ قلمرو قبلی سقوط می‌کند و آرتیفکت مجهز شده می‌شکند (مگر اینکه آیتم افسانه‌ای «عروسک جانشین» داشته باشد).
۳.۳. تعریف مهندسی شانس کارمایی (Karmic Luck Deep Mechanics)
شانس یک فاکتور تصادفی سطحی نیست؛ مقداری بین ۰ تا ۱۰۰ در دیتابیس است که ۴ بخش کلیدی بازی را مدیریت می‌کند:
1. تاس نجات معجزه‌آسا (Miracle Roll): اگر تاس صعود شکست بخورد، یک تاس ثانویه به اندازه مقدار شانس انداخته می‌شود. اگر موفق شود، پیام می‌دهد: «نسیم کارما وزید؛ صاعقه منحرف شد و بدون صدمه از مهلکه جستی!»
2. برخوردهای پربرکت در حالت AFK (Lucky Encounters): هر ساعت غیبت کاربر، اگر \text{Luck} > 70 باشد، احتمال ۵٪ وجود دارد که آیتم باستانی یا گنجینه مدفون بیابد. اگر \text{Luck} < 20 باشد، احتمال کمین راهزنان و سرقت چی وجود دارد.
3. تعدیل دمیج مصیبت آسمانی: نوسان دمیج صاعقه (مثلاً بین ۱۰,۰۰۰ تا ۳۰,۰۰۰). بازیکن خوش‌شانس کمترین دمیج ممکن را دریافت می‌کند.
4. تغییرات عددی کارما:
   * عوامل افزاینده: کمک به اعضای ضعیف فرقه (+۲)، بخشش در نبرد (+۱)، نجات جان فانی‌ها (+۵).
   * عوامل کاهنده: غارت وحشیانه دیگران (-۵)، استفاده از مراسم قربانی خونین (-۱۰)، فرار معجزه‌آسا از مرگ (-۱۵ مصرف مستقیم کارما).

	فصل ۵: موتور محاسبه آفلاین (AFK Tick) و کاتالیزورها
انرژی چی بازیکن در زمان عدم حضور، بر اساس فرمول جامع زیر محاسبه و ذخیره می‌شود:
\text{Qi Gain/Hour} = \left[ \text{Base}_{\text{realm}} \times \text{Tech}_{\text{mult}} \times (1 + \text{Catalyst}_{\text{boost}}) \times \text{Vein}_{\text{density}} \right] \times (1 + \text{Luck}_{\text{bonus}})
* \text{Base}_{\text{realm}}: نرخ پایه قلمرو فعلی (از ۱۰۰ در تصفیه چی تا ۱۰,۰۰۰ در صعود به مصیبت).
* \text{Tech}_{\text{mult}}: ضریب کیفی روش تهذیب مجهز شده (۱.۰ تا ۱۰.۰).
* \text{Catalyst}_{\text{boost}}: مجموع درصد بوست کاتالیزورهای فعال در دان‌تین.

۱۰.۲. موتور پایتون: محاسبه بازدهی AFK و شانس بریک‌ترو
import datetime
import random

class CultivationEngine:
   REALM_PENALTIES = {1: 0, 2: 10, 3: 20, 4: 35, 5: 50, 6: 65, 7: 80, 8: 90}
   BASE_RATES = {1: 100, 2: 300, 3: 800, 4: 2000, 5: 5000, 6: 12000, 7: 30000}

   @staticmethod
   def calculate_afk_gain(user: dict, current_time: datetime.datetime) -> int:
       """محاسبه دقیق چی تولید شده در بازه آفلاین"""
       last_time = datetime.datetime.fromisoformat(user["cultivation"]["last_afk_timestamp"])
       elapsed_hours = (current_time - last_time).total_seconds() / 3600.0

       if elapsed_hours <= 0:
           return 0

       realm_idx = user["cultivation"]["current_realm_index"]
       base_rate = CultivationEngine.BASE_RATES.get(realm_idx, 100)
       tech_mult = 1.5  # ضریب متد فعال
       catalyst_boost = 0.45  # برای سنگ روح میانه
       vein_density = user["location"]["vein_density"]
       luck_bonus = user["stats"]["hidden"]["karmic_luck"] * 0.002

       # فرمول جامع فصل ۵
       hourly_rate = (base_rate * tech_mult * (1 + catalyst_boost) * vein_density) * (1 + luck_bonus)
       total_gained = int(hourly_rate * elapsed_hours)

       # عدم تجاوز از ظرفیت دان‌تین
       current_qi = user["cultivation"]["qi_current"]
       capacity = user["cultivation"]["qi_capacity"]
       return min(total_gained, capacity - current_qi)

   @staticmethod
   def attempt_breakthrough(user: dict) -> dict:
       """بررسی ریاضی موفقیت، شکست و نجات کارمایی"""
       realm_idx = user["cultivation"]["current_realm_index"]
       hidden = user["stats"]["hidden"]

       base_chance = 25.0  # جهش بین قلمروها
       dao_heart_bonus = hidden["dao_heart_stability"] * 0.3
       pill_bonus = 20.0  # قرص محافظ
       luck_bonus = hidden["karmic_luck"] * 0.2
       corruption_penalty = hidden["demonic_corruption"] * 0.5
       realm_penalty = CultivationEngine.REALM_PENALTIES.get(realm_idx, 10)

       # فرمول نهایی بریک‌ترو
       success_rate = (base_chance + dao_heart_bonus + pill_bonus + luck_bonus 
                       - corruption_penalty - realm_penalty)
       success_rate = max(5.0, min(95.0, success_rate))  # کران‌دار بین ۵ تا ۹۵ درصد

       roll = random.uniform(0, 100)
       if roll <= success_rate:
           return {"status": "SUCCESS", "message_code": "BREAKTHROUGH_SUCCESS"}

       # مکانیک تاس نجات کارمایی (Miracle Roll)
       luck_roll = random.uniform(0, 100)
       if luck_roll <= hidden["karmic_luck"]:
           # مصرف کارما برای نجات
           user["stats"]["hidden"]["karmic_luck"] = max(0, hidden["karmic_luck"] - 15)
           return {"status": "MIRACLE_SAVED", "message_code": "KARMIC_LUCK_SALVATION"}

       # تعیین شدت شکست
       failure_type = random.choices(
           ["MINOR", "DEVIATION", "ANNIHILATION"],
           weights=[60, 30, 10]
       )[0]
